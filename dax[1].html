How to use DAX88

Everything you need in two minutes.

A single HTML file. Nothing to install, nothing to sign up for. Find the function, fill in your columns, copy, paste into Power BI.

Quick start

  1. Use search or pick a category at the top.
  2. Click any card to open the function detail.
  3. Fill in your table and column names.
  4. Watch the live preview update as you type.
  5. Click the copy icon (or press Ctrl+Shift+C) and paste it.

Measure vs Column

Every function carries a context badge telling you where it belongs:

Measure Recomputed on every query
Column Computed once at refresh
Both Works in either, behaviour differs

VAR / RETURN — start here

If you learn one thing from this library, make it variables. They break complex measures into readable steps and let you reuse a computed value without recalculating it.

VAR Name = <expression>
VAR Name2 = <expression>
RETURN <final expression>

Example data model

All examples use four tables. Rename them to match your model.

Sales — Amount, Qty, Price, Date, ProductKey, CustomerKey
Products — ProductKey, Name, Category, Price
Customers — CustomerKey, Name, Region
Dates — Date (marked as date table)
